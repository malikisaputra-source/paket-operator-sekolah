1

Rapikan data siswa

Nama, NISN 10 digit, tanggal, kelas, nomor HP diseragamkan. Data janggal dan dobel ditandai, bukan ditebak.

2

Buat surat .docx

Keterangan aktif, izin, undangan orang tua, lengkap dengan kop dan blok tanda tangan. Template JSON bisa ditambah.

3

Rekap absensi & nilai

Hadir/sakit/izin/alpa dan persen hadir; rata-rata, peringkat, mapel di bawah KKM.

Data siswa = data pribadi

Skrip berjalan lokal dan tidak mengirim apa pun ke internet. Tapi isi berkas yang dibaca agen AI ikut terkirim ke server model (Claude/OpenAI). Jangan unggah data siswa ke situs atau grup chat, pakai akun yang sesuai aturan sekolah, dan uji dulu dengan data contoh fiktif di folder contoh/.

Cara pakai

  1. Pasang Python 3, lalu pip install openpyxl python-docx.
  2. Ekstrak paket, isi contoh/sekolah.json dengan identitas sekolahmu.
  3. Buka folder di terminal, jalankan claude (atau codex).
  4. Tulis permintaan: "rapikan data siswa di berkas X", "buat surat izin untuk NISN …", "rekap absensi Oktober".
  5. Ambil hasil di folder hasil/, periksa, lalu cetak dan tanda tangani.
